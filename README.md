# FORCE LINK website

This is the website for FORCE LINK General Trading LLC. It is a plain static site, so there is no server or database to run. The pages are generated by a Python script and published with GitHub Pages.

## Folders

- `build/build_site.py` is the generator. Almost all of the text, the product list and the page layouts live here, so change them here and not in the HTML.
- `static/` holds the CSS and JavaScript that the generated pages load.
- `source-assets/` has the original images and logos. Keep the originals as they are.
- `site/` is the output of the build. You don't edit it by hand, and it gets overwritten on every build.
- `tests/` has a small Node test for the map coordinates.

## Building the site

You need Python 3 and Pillow:

```
pip install pillow
python3 build/build_site.py
```

The result goes into `site/`. Links are relative, so the site also works from a repository subpath such as `/Forcelink/`.

If you know the final address, set `SITE_URL` when you build. That adds canonical links, Open Graph tags, the sitemap and breadcrumb data:

```
SITE_URL=https://example.com/ python3 build/build_site.py
```

## Publishing

The site goes live with the GitHub Actions workflow in `.github/workflows/pages.yml`.

1. In the repository settings, open Pages and choose GitHub Actions as the source.
2. If you have the final address, add it as a repository variable called `SITE_URL`.
3. Push to `main`. The workflow builds the site and deploys it.

## The contact form

The site has no server, so the form does not send anything by itself. When someone submits it, their email app opens with the message filled in, addressed to info@forcelink-ae.com, and they press send. If you want the messages to arrive without an email app, you will need a form service. Put any keys on the service side, never in the JavaScript.
